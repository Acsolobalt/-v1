Программа Дуэль написана на C#.

Запускается через Дуэль.ехе файл в папке bin/Debug. 

Интерфейс поделен на 4 области: Создание первого/нового персонажа для сражений, поле прокачки, поле списка имеющихся персонажей и поле сражения. 
Персонаж может получать очки прокачки навыков в размере 1 ед. за 5 побед. Одно очко навыка можно потратить на улучшение любой из 6 характеристик на 1 ед.
Противник генерируется со случайными значениями характеристик, зависимых от уровня персонажа/главного героя.
В бою герой должен выбрать одно из двух действий перед ходом: атака или защита. На атаку тратится больше выносливости (4) чем на защиту (2).
Бой завершается, если здоровье персонажа = 0, либо если здоровье противника = 0.
